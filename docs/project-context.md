- 项目简介 PPT 是独立提交、供评委阅读的材料，不依赖旁白或现场演示。按赛事工作区材料控制在 20 页以内，包含团队介绍、项目介绍、需求分析和智能体开发设计。

- 现场路演与答辩属于决赛场景；需要时另做相应版本。
- 当前初赛审阅版本为 `deliverables/CampusOne_项目简介_v3.pptx`。此前含“路演答辩”的文件作为历史版本保留。
