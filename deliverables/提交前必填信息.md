# 提交前必填信息

当前产品、文档、PPT、真人视频脚本和录制指南均已生成。由于尚未收到真实参赛信息，下列内容必须由参赛者补齐后再正式上传：

- 参赛单位全称
- 队长和全部团队成员真实姓名及顺序
- 指导教师姓名
- 联系邮箱
- 赛事平台最终要求的文件名、文件大小和提交入口

请只修改仓库根目录的 `competition.config.json`，再重建 Word 与 PPT，避免多份材料身份信息不一致。

正式提交前还要完成两项人工工作：一是由业务教师核对场地规则和表述；二是由参赛者按录制指南真人讲解并录制实机操作，导出 3–5 分钟 MP4。

不要在聊天、仓库或前端代码中提交 API Key。切换真实模型时，只把密钥写入本地或部署端的私有环境变量。
